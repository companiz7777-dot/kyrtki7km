# Папка для нових фото

Перетягніть сюди фото з комп'ютера (на github.com: **Add file → Upload files**).

Найзручніше — окремою папкою на кожну модель, наприклад `incoming/Tartufo/`.
Можна й просто купою: Claude перегляне фото й сам розкладе їх по моделях.

Після обробки фото переносяться в `img/`, а ця папка знову порожніє.
