# Як підключити базу (Supabase) — один раз, ~15 хвилин

Supabase — це безкоштовна онлайн-база даних. У ній зберігатимуться ціни в $, курс, наявність і журнал змін.
Сайт на Netlify читатиме звідти актуальні ціни, а адмінка — записуватиме зміни.

## 1. Створити проєкт
1. Зайдіть на https://supabase.com → **Start your project** → увійдіть (можна через Google).
2. **New project**: назва `kurtki7km`, регіон **Central EU (Frankfurt)**, придумайте пароль бази (збережіть у надійному місці, нікому не надсилайте).
3. Зачекайте 1–2 хвилини, поки проєкт створиться.

## 2. Створити таблиці
1. Ліве меню → **SQL Editor** → **New query**.
2. Відкрийте файл `supabase/schema.sql`, скопіюйте весь текст, вставте → **Run**. Має з’явитися «Success».

## 3. Створити свій вхід в адмінку
1. Ліве меню → **Authentication** → **Users** → **Add user** → **Create new user**.
2. Ваш e-mail і пароль для адмінки (пароль вводите тільки ви). Поставте галочку **Auto Confirm User**.
3. Знову **SQL Editor** → New query → вставте (замініть e-mail на свій) → **Run**:
   ```sql
   insert into public.admins(user_id, email, role)
   select id, email, 'owner' from auth.users where email = 'ВАШ@EMAIL';
   ```
   Для менеджера (може міняти товари, але не курс) — те саме, але `'manager'`.
4. **Authentication → Sign In / Providers → Email**: вимкніть **Allow new users to sign up**, щоб ніхто сторонній не реєструвався.

## 4. Передати мені два ключі
Ліве меню → **Project Settings** → **API**:
- **Project URL** (вигляд `https://xxxx.supabase.co`)
- **anon public** key

Ці два значення публічні — їх можна надіслати мені в чат, я впишу в `js/config.js`.
**Ключ `service_role` НІКОМУ не надсилайте і нікуди не вставляйте** — це «ключ від усього».

## 5. Перший запуск
1. Відкрийте `ваш-сайт/admin/` → увійдіть.
2. Адмінка побачить порожню базу і запропонує **«Перенести каталог»** — натисніть. Усі моделі переїдуть у базу.
3. Вкладка **Курс $** → встановіть актуальний курс.
4. Перевірте ціни в $ у вкладці **Товари**.

## Як це працює
- Ціна на сайті = ціна в $ × останній курс, округлено до 10 ₴. Рахує база, не браузер.
- Усі розміри = 0 або «Сховати» → товар зникає з сайту, але лишається в адмінці.
- Кожна зміна ціни, курсу, наявності записується в **Журнал** (хто і коли). Історію не можна стерти.
- Якщо база раптом недоступна — сайт показує останню збережену версію каталогу з файлів.
